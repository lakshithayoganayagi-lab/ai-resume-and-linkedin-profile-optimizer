AI Resume and LinkedIn Profile Optimizer

Project Description

This project aims to help students and job seekers improve their resumes and LinkedIn profiles using AI-based suggestions.

Objectives

- Analyse resume content.
- Identify missing keywords.
- Improve professional summaries.
- Suggest LinkedIn profile improvements.

Technologies Used

- Python
- Natural Language Processing (NLP)
- Streamlit
- GitHub
